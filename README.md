# 고래상사 크루 미니 대시보드

고래상사 크루 멤버들을 한 화면에서 동시에 추적하는 대시보드예요.
각 멤버별로 방송 중인지, 채팅 접속자 수(실측치), 오늘 별풍선 합계, 최근 후원 로그를 보여줘요.

## 1. 멤버 아이디 채우기 (제일 중요!)

`crew.js` 파일을 여세요. 이렇게 생겼어요:

```js
module.exports = [
  { id: 'bach023', name: '울산큰고래' }, // 확인됨
  { id: '', name: '견자희' },            // <- 여기 비어있음, 채워야 함
  { id: '', name: '감자가비' },
  ...
];
```

각 멤버의 SOOP 방송국 주소(`https://ch.sooplive.co.kr/여기부분`)에서 아이디를 찾아
`id: ''` 사이에 넣어주세요. 예: `{ id: 'gyeonjahee', name: '견자희' }`

**id가 빈칸(`''`)인 멤버는 자동으로 대시보드에서 빠져요.** 아는 멤버부터 하나씩 채워도 됩니다.

## 2. 실행

```bash
npm install
node server.js
```

`http://localhost:3000` 접속.

(예전 버전과 다르게 이제 `STREAMER_ID` 환경변수는 안 써요. `crew.js`에 등록된 멤버를 전부 동시에 봅니다.)

## ⚠️ 알아둘 것

- **네트워크 미검증**: 이 코드는 샌드박스 환경이라 실제로 붙여보진 못했어요. 로컬에서 실행 후 에러 나면 캡처해서 보여주세요.
- **채팅 접속자 수는 실제 시청자 수와 100% 같지 않아요.** 채팅 소켓 입장/퇴장 이벤트를 직접 세는 방식이라, 서버를 방송 시작 직후부터 켜둘수록 더 정확해져요. (자세한 이유는 대화 중 설명드린 내용 참고)
- 멤버 수가 많을수록 동시에 여러 웹소켓 연결을 유지해요. 너무 많으면(수십 명 이상) SOOP 쪽에서 이상 트래픽으로 인식할 수 있으니, 크루 규모(16명) 정도면 괜찮지만 무한정 늘리진 마세요.
- 서버를 껐다 켜면 오늘 집계가 초기화돼요. 계속 누적하려면 SQLite 같은 DB 연결이 필요해요.
- 비공식 방식이라 SOOP이 프로토콜을 바꾸면 언제든 안 될 수 있어요.
- 개인 프로젝트/팬 활동 목적으로만 쓰세요.
